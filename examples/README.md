# Examples

| File | What it shows |
| --- | --- |
| [send-message.ts](send-message.ts) | Text someone, then read the message's status |
| [webhook-server.ts](webhook-server.ts) | Receive webhooks, verify the signature, handle new messages |

Run them with [tsx](https://tsx.is) from a project that has `blujay` installed. Guides for every feature are at [docs.blujay.io](https://docs.blujay.io).
